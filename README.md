# ∑ MathKey

### Mathematical symbols, one keyboard.

**MathKey is a dedicated Android keyboard for mathematical symbols and Greek letters.**

Mathematics has its own alphabet. MathKey brings that alphabet to your fingertips.

From Greek letters and arithmetic operators to calculus notation, set theory, and mathematical logic, MathKey provides a convenient way to enter specialized characters directly into text fields on your Android device.

No need to search for individual symbols every time you need one. Simply switch to MathKey, find the character, and type.

---

## ✦ Features

### Greek Alphabet

Access Greek letters commonly used in mathematics, physics, engineering, and scientific notation.

`α β γ δ ε θ λ π σ Ω`

### Mathematical Operators

Enter arithmetic operators, comparison symbols, roots, and other mathematical notation.

`± ∓ × ÷ ≠ ≈ ≤ ≥ √ ∞`

### Calculus & Analysis

Quick access to symbols used in calculus and mathematical analysis.

`∑ ∏ ∫ ∮ ∂ ∇`

### Sets & Logic

Type set relations, logical operators, quantifiers, and number-set symbols.

`∈ ∉ ⊂ ⊆ ∩ ∪ ∅ ∀ ∃ ⇒`

### Geometry & Specialized Notation

Use angle, perpendicularity, parallelism, and other mathematical notation.

`∠ ⊥ ∥ ∴ ∵`

### Five-Page Layout

Navigate between five pages of characters using the built-in page control. Related symbols are arranged together, keeping the interface compact and straightforward.

### Essential Keyboard Controls

Backspace, Space, and Enter are available alongside the symbol keys.

### Dark Interface

A dark background, gray keys, and white characters create a consistent, high-contrast appearance.

---

## ⌨️ Designed for Direct Input

MathKey works as an Android input method, allowing supported characters to be inserted directly into the active text field.

For example, you can type:

**Algebra**

`α + β = γ`

**Calculus**

`∫ f(x) dx`

**Radicals**

`√(x² + 1)`

**Set Theory**

`A ∩ B ≠ ∅`

**Scientific Notation**

`Δx → 0`

These examples illustrate possible uses of mathematical characters; they are not automatically formatted equations.

## Getting Started

### Requirements

- An Android device.
- The MathKey APK.
- Access to Android's keyboard settings.

### Installation

1. Download the MathKey APK from the project's GitHub Releases page.
2. Install the APK on your device.
3. Open your device's keyboard settings.
4. Find the section for on-screen keyboards or managing input methods.
5. Enable MathKey.
6. Open an application with a text field and select MathKey using the system keyboard switcher.

The exact settings path may vary depending on your device manufacturer and Android version.

### Basic Usage

- **Insert a symbol:** Tap the corresponding key.
- **Change pages:** Tap the page indicator to move through the available pages.
- **Delete text:** Use Backspace.
- **Insert a space:** Use Space.
- **Send Enter:** Use the Enter key.

Switch back to your regular keyboard whenever you need ordinary text input.

---

## Scope & Compatibility

MathKey is designed for entering mathematical characters into ordinary text fields. It is not a symbolic mathematics engine or a full equation editor.

- Mathematical expressions are entered as text.
- Fractions can be written using conventional notation, such as `a / b`.
- Stacked fractions and automatically formatted, two-dimensional equations are not provided.
- Symbol appearance depends on the fonts and rendering support of the receiving application.
- Keyboard behavior may vary between applications, particularly for Enter and text editing.

MathKey focuses on direct character entry rather than complex equation formatting.
